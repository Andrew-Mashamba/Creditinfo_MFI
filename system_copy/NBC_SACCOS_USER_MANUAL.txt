HOW TO USE:

Creating a New User:
1. Navigate to Users Manager
2. Click "Add New User"
3. Enter user details
4. Assign branch
5. Select role(s)
6. Set initial password
7. Save user account

Assigning Roles:
1. Go to Users Manager > Roles
2. Select user
3. Add or remove roles
4. Save changes

Configuring Permissions:
1. Navigate to Permissions Management
2. Select role
3. Check/uncheck permissions
4. Save permission settings
