## Enhanced Security Headers

### File Created
**Path**: `/app/Http/Middleware/EnhancedSecurityHeaders.php`

### Registered In
- Web middleware group (automatic for all web routes)
- Route middleware: `enhanced.security`
- Middleware alias: `enhanced.security`

### Security Headers Applied

| Header | Value | Purpose |
|--------|-------|---------|
| **Content-Security-Policy** | Strict with nonce | XSS prevention |
| **X-Frame-Options** | SAMEORIGIN | Clickjacking prevention |
| **X-Content-Type-Options** | nosniff | MIME sniffing prevention |
| **X-XSS-Protection** | 1; mode=block | Legacy XSS filter |
| **Referrer-Policy** | strict-origin-when-cross-origin | Information leakage prevention |
| **Permissions-Policy** | Restrictive | Browser feature control |
| **Strict-Transport-Security** | max-age=31536000 | HTTPS enforcement |
| **Expect-CT** | max-age=86400, enforce | Certificate Transparency |
| **Cross-Origin-Opener-Policy** | same-origin | Browsing context isolation |
| **Cross-Origin-Embedder-Policy** | require-corp | Resource isolation |
| **Cross-Origin-Resource-Policy** | same-origin | Resource sharing control |
| **X-Permitted-Cross-Domain-Policies** | none | Flash/PDF policy |

### CSP Directives

```
Content-Security-Policy:
  default-src 'self';
  script-src 'self' 'nonce-{RANDOM}' 'unsafe-eval' 'strict-dynamic';
  style-src 'self' 'nonce-{RANDOM}' 'unsafe-inline';
  img-src 'self' data: blob: https:;
  font-src 'self' data:;
  connect-src 'self';
  frame-src 'self';
  object-src 'none';
  media-src 'self' blob:;
  form-action 'self';
  frame-ancestors 'self';
  base-uri 'self';
  worker-src 'self' blob:;
  manifest-src 'self';
  child-src 'self';
  upgrade-insecure-requests;
  block-all-mixed-content;
```

### Nonce Generation

Every request gets a unique cryptographically secure nonce:

```php
// Automatically generated by middleware
$nonce = base64_encode(random_bytes(16));

// Shared with all views
view()->share('cspNonce', $nonce);

// Accessible in controllers
$request->attributes->get('csp_nonce');
```

## XSS Protection Middleware

### File Created
**Path**: `/app/Http/Middleware/XssProtection.php`

### Registered In
- Web middleware group (automatic for all web requests)
- Route middleware: `xss.protection`
- Middleware alias: `xss.protection`

### What It Does

1. **Sanitizes Input**: Automatically cleans dangerous patterns from user input
2. **Removes Dangerous Strings**: Blocks javascript:, vbscript:, data:text/html protocols
3. **Strips HTML Tags**: Removes <script>, <iframe>, <object>, etc.
4. **Removes Event Handlers**: Strips onclick=, onerror=, onload=, etc.
5. **Cleans JavaScript**: Removes HTML comments and dangerous patterns

### Excluded Fields

Fields that are sanitized by HTMLPurifier instead:
- `content`
- `description`
- `body`
- `message`
- `signature`
- `template`

### Example

**Input**:
```php
$request->input('name') = "<script>alert('XSS')</script>John";
```

**After XSS Middleware**:
```php
$request->input('name') = "John";
```

## Security Helper Functions

### File Created
**Path**: `/app/Helpers/SecurityHelpers.php`

### Registered In
**File**: `composer.json` autoload files section

### Available Functions

#### 1. csp_nonce()

Get the current CSP nonce for inline scripts:

```blade
<script nonce="{{ csp_nonce() }}">
    console.log('This script is allowed by CSP');
</script>

<style nonce="{{ csp_nonce() }}">
    .secure { color: green; }
</style>
```

#### 2. safe_html($html, $config = 'default')

Sanitize HTML using HTMLPurifier:

```blade
{{-- Safe HTML rendering --}}
{!! safe_html($userContent) !!}

{{-- With specific config --}}
{!! safe_html($emailSignature, 'email') !!}
```

#### 3. safe_json($data)

Safely encode data for JavaScript:

```blade
<script nonce="{{ csp_nonce() }}">
    const userData = {!! safe_json($user) !!};
</script>
```

Output:
```javascript
const userData = {"name":"John\u0027s","email":"john@example.com"};
```

#### 4. safe_url($url, $allowedProtocols = ['http', 'https'])

Sanitize URLs to prevent javascript: protocol XSS:

```blade
{{-- Safe URL --}}
<a href="{{ safe_url($userProvidedUrl) }}">Link</a>

{{-- Custom allowed protocols --}}
<a href="{{ safe_url($url, ['http', 'https', 'mailto']) }}">Email Link</a>
```

**Example**:
```php
safe_url('javascript:alert("XSS")'); // Returns: '' (empty)
safe_url('https://example.com'); // Returns: 'https://example.com'
```

#### 5. safe_attribute($value)

Sanitize for HTML attributes:

```blade
<div data-name="{{ safe_attribute($userName) }}" data-value="{{ safe_attribute($userValue) }}">
    Content
</div>
```

#### 6. safe_js_string($value)

Sanitize for JavaScript string literals:

```blade
<script nonce="{{ csp_nonce() }}">
    const message = '{{ safe_js_string($userMessage) }}';
</script>
```

#### 7. strip_dangerous_tags($html)

Strip dangerous HTML tags:

```php
$clean = strip_dangerous_tags('<div>Safe</div><script>alert("XSS")</script>');
// Result: '<div>Safe</div>'
```

#### 8. is_safe_redirect($url)

Check if redirect URL is safe (same origin):

```php
if (is_safe_redirect($redirectUrl)) {
    return redirect($redirectUrl);
} else {
    return redirect()->route('home');
}
```

#### 9. sanitize_filename($filename)

Sanitize filenames to prevent directory traversal:

```php
$safe = sanitize_filename('../../etc/passwd');
// Result: 'etc_passwd'

$safe = sanitize_filename('<script>alert.txt');
// Result: '_script_alert.txt'
```

## CSP Nonce Implementation

### How It Works

1. **Middleware Generates Nonce**: Each request gets a unique nonce
2. **Nonce Shared with Views**: Available as `$cspNonce` or via `csp_nonce()`
3. **CSP Header Includes Nonce**: `script-src 'nonce-{RANDOM}'`
4. **Scripts Must Have Nonce**: Only scripts with correct nonce execute

### Blade Template Example

```blade
<!DOCTYPE html>
<html>
<head>
    {{-- Always set charset first --}}
    <meta charset="UTF-8">

    <title>{{ config('app.name') }}</title>

    {{-- Inline styles need nonce --}}
    <style nonce="{{ csp_nonce() }}">
        body { margin: 0; }
    </style>
</head>
<body>
    {{-- Safe escaped output --}}
    <h1>Welcome {{ $user->name }}</h1>

    {{-- Safe HTML with HTMLPurifier --}}
    <div class="content">
        {!! safe_html($content) !!}
    </div>

    {{-- External scripts don't need nonce (allowed by 'self') --}}
    <script src="{{ asset('js/app.js') }}"></script>

    {{-- Inline scripts MUST have nonce --}}
    <script nonce="{{ csp_nonce() }}">
        console.log('User ID: {{ $user->id }}');

        // Safe JSON data
        const userData = {!! safe_json($user) !!};

        // Use textContent, not innerHTML
        document.getElementById('welcome').textContent = '{{ safe_js_string($welcomeMessage) }}';
    </script>
</body>
</html>
```

## Blade Template Guidelines

### ✅ CORRECT Examples

#### 1. Escaped Output (Default - Always Safe)

```blade
{{-- Auto-escaped - SAFE --}}
{{ $userInput }}
{{ $user->name }}
{{ $post->title }}
```

Laravel automatically escapes `{{ }}` output with `htmlspecialchars()`.

#### 2. Safe HTML with Sanitization

```blade
{{-- HTMLPurifier sanitized - SAFE --}}
{!! clean($richContent, 'email') !!}
{!! safe_html($userHtml) !!}
```

#### 3. Safe URLs

```blade
{{-- Safe URL helper - SAFE --}}
<a href="{{ safe_url($userUrl) }}">Link</a>
<a href="{{ url($internalPath) }}">Internal</a>
<a href="{{ route('user.profile', $user) }}">Profile</a>
```

#### 4. Safe Attributes

```blade
{{-- Auto-escaped in attributes - SAFE --}}
<input type="text" value="{{ $userInput }}" />
<div data-name="{{ $user->name }}"></div>
```

#### 5. Safe JSON in JavaScript

```blade
<script nonce="{{ csp_nonce() }}">
    // Using @json directive - SAFE
    const data = @json($data);

    // Using safe_json helper - SAFE
    const user = {!! safe_json($user) !!};
</script>
```

#### 6. Inline Scripts with Nonce

```blade
{{-- Always include nonce for inline scripts - SAFE --}}
<script nonce="{{ csp_nonce() }}">
    document.addEventListener('DOMContentLoaded', function() {
        console.log('Page loaded');
    });
</script>
```

#### 7. Event Listeners (NOT Inline Handlers)

```blade
{{-- Use addEventListener - SAFE --}}
<button id="submit-btn">Submit</button>

<script nonce="{{ csp_nonce() }}">
    document.getElementById('submit-btn').addEventListener('click', function() {
        // Handle click
    });
</script>
```

#### 8. Forms with CSRF

```blade
{{-- Always include @csrf - SAFE --}}
<form method="POST" action="{{ route('user.update') }}">
    @csrf
    <input type="text" name="name" value="{{ old('name', $user->name) }}" />
    <button type="submit">Save</button>
</form>
```

### ❌ INCORRECT Examples (DO NOT USE)

#### 1. Unescaped User Input

```blade
{{-- DANGEROUS - XSS VULNERABILITY --}}
{!! $userInput !!}
{!! $post->content !!}
```

**Why**: Executes any JavaScript in the variable.

**Fix**: Use `{{ $var }}` or sanitize with HTMLPurifier first.

#### 2. Unsafe URLs

```blade
{{-- DANGEROUS - javascript: protocol --}}
<a href="{!! $userUrl !!}">Link</a>
```

**Why**: User could provide `javascript:alert('XSS')`.

**Fix**: Use `safe_url()` helper.

#### 3. innerHTML with User Data

```blade
<script nonce="{{ csp_nonce() }}">
    // DANGEROUS
    document.getElementById('content').innerHTML = '{!! $userContent !!}';
</script>
```

**Why**: innerHTML executes scripts.

**Fix**: Use `textContent` or sanitize first.

#### 4. Inline Scripts without Nonce

```blade
{{-- DANGEROUS - Will be blocked by CSP --}}
<script>
    console.log('This will not execute');
</script>
```

**Why**: CSP blocks inline scripts without nonce.

**Fix**: Add `nonce="{{ csp_nonce() }}"`.

#### 5. Inline Event Handlers

```blade
{{-- DANGEROUS - Blocked by CSP --}}
<button onclick="alert('XSS')">Click</button>
<img src="invalid" onerror="alert('XSS')" />
```

**Why**: CSP blocks inline event handlers.

**Fix**: Use `addEventListener` in JavaScript.

#### 6. eval() and Function()

```blade
<script nonce="{{ csp_nonce() }}">
    // DANGEROUS
    eval(userCode);
    new Function(userCode)();
</script>
```

**Why**: Executes arbitrary code.

**Fix**: Never execute user-provided code.

#### 7. document.write()

```blade
<script nonce="{{ csp_nonce() }}">
    // DANGEROUS - Deprecated
    document.write('<div>' + userContent + '</div>');
</script>
```

**Why**: Can inject malicious scripts.

**Fix**: Use DOM methods (createElement, textContent).

## Troubleshooting

### Issue: CSP Blocking Legitimate Scripts

**Symptoms**: Console shows CSP violations for your own scripts.

**Solution**: Add nonce to inline scripts:
```blade
<script nonce="{{ csp_nonce() }}">
    // Your code
</script>
```

### Issue: External CDN Scripts Blocked

**Symptoms**: CDN scripts (jQuery, Bootstrap) not loading.

**Solution**: Add CDN to trusted sources in `EnhancedSecurityHeaders.php`:
```php
protected function getTrustedScriptSources(): string
{
    $sources = [
        'https://cdn.jsdelivr.net',
        'https://cdnjs.cloudflare.com',
    ];
    return implode(' ', $sources);
}
```

### Issue: Images Not Loading

**Symptoms**: Images from external sources blocked.

**Solution**: CSP already allows `https:` for images. Check if images use HTTP (upgrade to HTTPS).

### Issue: HTMLPurifier Too Restrictive

**Symptoms**: Safe HTML tags being stripped.

**Solution**: Add tags to allowed list in `/config/purifier.php`:
```php
'HTML.Allowed' => 'p,br,strong,... ,newtag',
```

### Issue: Forms Not Submitting

**Symptoms**: 419 CSRF token mismatch errors.

**Solution**: Ensure form has `@csrf`:
```blade
<form method="POST">
    @csrf
    {{-- form fields --}}
</form>
```

### Issue: XSS Middleware Breaking Features

**Symptoms**: Legitimate HTML content being stripped.

**Solution**: Add field to excluded list in `XssProtection.php`:
```php
protected $excludedFields = [
    'content',
    'description',
    'body',
    'your_field_name',
];
```
